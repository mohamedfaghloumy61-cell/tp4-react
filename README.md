# Creative Recipe Builder — TP4 React

Correction du TP4 avec les composants demandés : RecipeItem, RecipeList, RecipeForm, RecipeFilter, Pagination, Aide et la page principale.

## Lancer le projet
1. Extraire le fichier ZIP.
2. Ouvrir le dossier dans le terminal.
3. Exécuter `npm install`.
4. Exécuter `npm start`.

La liste de recettes est vide au départ : aucune donnée de démonstration ni fichier `data.js` n'est ajouté.
